# Corso di Russo da Zero

Corso completo di lingua russa organizzato per argomenti, con cirillico, traslitterazione, pronuncia e traduzione italiana.

Ogni voce segue questo formato:

| Cirillico | Traslitterazione | Pronuncia | Italiano |
|-----------|-----------------|-----------|----------|
| Привет | Privet | pri-VYÈT | Ciao |
