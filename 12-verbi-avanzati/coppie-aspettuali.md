# 12b - Coppie Aspettuali: Drill di 40 Verbi

L'**aspetto verbale** è la chiave per parlare russo. Ogni verbo russo esiste in **due forme**: imperfettivo (azione in corso, abituale, ripetuta) e perfettivo (azione completata, risultato).

> Regola d'oro: **non si impara mai un verbo da solo**, sempre la **coppia**. Es. non "lavorare" ma **работать / поработать**.

---

## 1. Il principio in 30 secondi

| Imperfettivo (ipf) | Perfettivo (pf) |
|--------------------|-----------------|
| Azione in corso | Azione completata |
| Abituale, ripetuta | Una volta, risultato |
| "Stavo facendo" | "Ho fatto / Avrò fatto" |
| Presente / passato / futuro composto | Solo passato / futuro semplice |

**Esempi paralleli**:

| Italiano | Imperfettivo | Perfettivo |
|----------|--------------|------------|
| Leggevo il libro (in corso) | Я читал книгу | — |
| Ho letto il libro (finito) | — | Я прочитал книгу |
| Leggerò (in corso, abituale) | Я буду читать | — |
| Leggerò (una volta, fino in fondo) | — | Я прочитаю |

---

## 2. Come si formano le coppie (3 schemi)

### Schema A — prefisso (più comune)

L'ipf base + prefisso → pf.

| Prefisso comune | Esempio | Significato |
|-----------------|---------|-------------|
| про- | читать / **про**читать | leggere / leggere fino in fondo |
| на- | писать / **на**писать | scrivere / scrivere fino a finire |
| с- | делать / **с**делать | fare / aver fatto |
| по- | смотреть / **по**смотреть | guardare / dare un'occhiata |
| вы- | пить / **вы**пить | bere / bere tutto |
| у- | видеть / **у**видеть | vedere / scorgere |

### Schema B — suffisso (cambia il suffisso)

| Imperfettivo | Perfettivo | Significato |
|--------------|------------|-------------|
| открыв**а**ть | откр**ы**ть | aprire |
| закрыв**а**ть | закр**ы**ть | chiudere |
| покуп**а**ть | куп**и**ть | comprare |
| отвеч**а**ть | ответ**и**ть | rispondere |
| повтор**я**ть | повтор**и**ть | ripetere |
| реш**а**ть | реш**и**ть | risolvere/decidere |

### Schema C — completamente diverse (memorizzale)

| Imperfettivo | Perfettivo | Significato |
|--------------|------------|-------------|
| говорить | сказать | parlare / dire |
| брать | взять | prendere |
| класть | положить | mettere (in piano) |
| ставить | поставить | mettere (in piedi) |
| ловить | поймать | catturare |
| искать | найти | cercare / trovare |

## 4. Test concreto: scegli l'aspetto

Per ogni frase, scegli la forma giusta. La risposta è nella riga dopo.

| Frase italiana | Imperfettivo o perfettivo? |
|----------------|----------------------------|
| Ieri ho letto il libro (tutto). | perfettivo → Я прочитал книгу |
| Ieri leggevo (mentre tu chiamavi). | imperfettivo → Я читал |
| Ogni sera leggo un libro. | imperfettivo → Я читаю |
| Domani leggerò il libro (fino in fondo). | perfettivo → Я прочитаю |
| Sto leggendo. | imperfettivo → Я читаю |
| Spesso compro pane. | imperfettivo → Я покупаю |
| Stamattina ho comprato pane. | perfettivo → Я купил |
| Compro questo libro! (decisione, una volta) | perfettivo → Я куплю |
| Stavo aprendo la porta. | imperfettivo → Я открывал |
| Ho aperto la porta. | perfettivo → Я открыл |

## 5. Marcatori temporali (ti dicono quale aspetto usare)

### Marcatori da imperfettivo

| Espressione | Significato |
|-------------|-------------|
| всегда | sempre |
| часто | spesso |
| иногда | a volte |
| каждый день / неделю / год | ogni giorno / settimana / anno |
| обычно | di solito |
| редко | raramente |
| долго | a lungo |
| два часа (durata) | per due ore |
| пока | mentre |

### Marcatori da perfettivo

| Espressione | Significato |
|-------------|-------------|
| вдруг | improvvisamente |
| наконец | finalmente |
| уже | già (con risultato) |
| сразу | subito |
| вчера утром | ieri mattina (puntuale) |
| за час (in un'ora) | in un'ora (compimento) |

## 6. Verbi di movimento (caso speciale: 2 imperfettivi)

I verbi di movimento hanno **due imperfettivi**: uno **unidirezionale** (in una direzione, in corso ora), uno **multidirezionale** (abituale, andata e ritorno, generale).

| Multidirezionale | Unidirezionale | Perfettivo (con prefisso) | Italiano |
|------------------|----------------|---------------------------|----------|
| ходить | идти | пойти | andare a piedi |
| ездить | ехать | поехать | andare con mezzo |
| летать | лететь | полететь | volare |
| плавать | плыть | поплыть | nuotare |
| бегать | бежать | побежать | correre |
| носить | нести | понести | portare |

**Esempi**:

| Frase | Verbo usato | Perché |
|-------|-------------|--------|
| Я **иду** в спортзал (ora, in quel momento). | идти | unidirezionale, in corso |
| Я **хожу** в спортзал каждый день. | ходить | multidirezionale, abituale |
| Я **поеду** в Москву завтра. | поехать | perfettivo (puntuale, futuro) |
| Я часто **езжу** в Россию. | ездить | multidirezionale, frequenza |

## 7. Imperfettivo o perfettivo? — Domande chiave

Prima di scegliere, chiediti:

1. **L'azione è completata** (ha un risultato)? → perfettivo.
2. **È in corso ora, era in corso, sarà in corso**? → imperfettivo.
3. **È abituale, ripetuta**? → imperfettivo.
4. **È una volta sola, puntuale**? → spesso perfettivo.
5. **C'è una durata** (per X ore)? → imperfettivo.
6. **C'è un "fino a"** (entro X ore)? → perfettivo.

---

## 8. Mini-storia con aspetto (memorizzala)

> Каждый день я **читаю** (ipf, abituale) книгу. Вчера я **прочитал** (pf, finito) "Войну и мир". Когда я **читал** (ipf, in corso), позвонил друг. Я **поговорил** (pf, finito) с ним и **продолжил** (pf) читать.

| Forma | Aspetto | Perché |
|-------|---------|--------|
| читаю | ipf | abituale |
| прочитал | pf | risultato (libro finito) |
| читал | ipf | in corso quando è successo qualcosa |
| поговорил | pf | conversazione finita |
| продолжил | pf | azione singola di "ripresa" |
